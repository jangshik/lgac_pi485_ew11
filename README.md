# LG AC PI485 (EW11) Integration for Home Assistant

LG 시스템 에어컨 및 가정용 에어컨을 PI485 인터페이스와 RS485 to TCP 게이트웨이(Elfin EW11 등)를 통해 Home Assistant에 연결하고 제어하는 커스텀 통합구성요소(Custom Component)입니다.

이 통합구성요소는 통신 안정성을 극대화하고, LG의 상업용 빌딩 제어망(LonWorks) 표준 센서 데이터를 분석하여 홈어시스턴트에서 에어컨의 실시간 부하 상태를 정밀하게 모니터링할 수 있도록 설계되었습니다.

## ✨ 주요 기능 (Features)

* **UI 기반 간편 설정 (Config Flow):** `configuration.yaml`을 수정할 필요 없이, HA의 '기기 및 서비스' UI 화면에서 직관적으로 IP, 포트, 옵션을 설정할 수 있습니다.
* **명령어 헤더 맞춤 선택 (Legacy / LGAP):** 에어컨 기판 특성에 맞춰 기본 LGAP 표준 규격(`00 00 A0`)과 특수 제어를 위한 레거시 규격(`80 00 A3`)을 UI에서 바로 선택할 수 있어 정음(Silent)/터보(Turbo) 모드 호환성이 뛰어납니다.
* **능동형 기기 스캔 (Active Discovery):** 설치 시 RS485 버스를 스캔하여 연결된 에어컨의 실제 하드웨어 통신 주소(Zone Number)를 자동으로 찾아냅니다.
* **다배관/단배관 맞춤형 온도 제어:** 시스템 에어컨(다배관, M)과 가정용 2in1(단배관, S)의 통신 규격 차이를 반영하여 설정 온도가 튀는 현상을 완벽하게 방지합니다.
* **스마트 상태 필터링 (Smart State Deduplication):** 무의미한 센서 노이즈를 걸러내고, 에어컨의 유의미한 상태(온도, 부하율 등)가 변했을 때만 HA 데이터베이스에 기록하여 서버 부하를 획기적으로 줄입니다.
* **소프트웨어 수면 타이머:** HA 서버 시간을 기준으로 카운트다운하며, 시간이 0이 되면 기기의 상태를 보존한 채 안전하게 OFF 명령을 전송합니다.
* **HACS 브랜드 아이콘 네이티브 지원:** HA UI에서 기본 퍼즐 아이콘 대신 LG 에어컨과 RS485 통신을 상징하는 전용 브랜드 아이콘이 표시됩니다.

## 🔌 하드웨어 요구사항 (Hardware Requirements)

1. **LG PI485 모듈:** 에어컨 실외기 또는 실내기에 연결되어 RS485 통신을 지원하는 모듈 (예: PMNFP14A1 등)
2. **RS485 to TCP/IP 게이트웨이:** Elfin EW11, USR-TCP232 등 (네트워크를 통해 Serial 데이터를 소켓으로 전송할 수 있는 기기)
3. **Home Assistant OS / Core**

## 📥 설치 방법 (Installation)

### 방법 1: HACS를 통한 설치 (권장)
1. Home Assistant에서 HACS 메뉴로 이동합니다.
2. 우측 상단의 점 3개(⋮) 메뉴를 누르고 **'사용자 지정 저장소(Custom repositories)'**를 선택합니다.
3. 이 GitHub 저장소의 URL(`https://github.com/사용자계정/lgac_pi485_ew11`)을 입력하고, 카테고리를 **'통합구성요소(Integration)'**로 선택하여 추가합니다.
4. 목록에 나타난 "LG AC PI485 EW11"을 다운로드하고 Home Assistant를 재시작합니다.
5. **[필수]** 브라우저 캐시를 지우기 위해 `Ctrl + Shift + R`을 눌러 강력 새로고침을 합니다.

### 방법 2: 수동 설치 (Manual)
1. HA 설정 폴더의 `custom_components` 디렉토리 안에 `lgac_pi485_ew11` 폴더를 생성합니다.
2. 이 저장소의 모든 파일을 해당 폴더로 복사합니다.
3. Home Assistant를 재시작하고 강력 새로고침(`Ctrl + Shift + R`)을 합니다.

## ⚙️ 설정 방법 (Configuration)

1. Home Assistant의 **설정 > 기기 및 서비스 > 통합구성요소 추가**를 클릭합니다.
2. **"LG 에어컨 (LG AC PI485 EW11)"**을 검색하여 선택합니다.
3. 설정 창에서 아래 정보를 입력합니다:
   * **IP 주소 및 포트:** EW11 게이트웨이의 정보
   * **명령어 헤더 방식:** 
     * *레거시 방식 (`80 00 A3`):* 기존 스크립트 사용자 및 정음/터보 등 특수 기능 제어가 필요한 기판
     * *LGAP 표준 방식 (`00 00 A0`):* 오픈소스 표준 규격을 따르는 일반 기판
   * **업데이트 주기 & 스캔 대기 시간:** 네트워크 환경에 맞게 설정
4. 다음으로 넘어가면, 시스템이 자동으로 연결된 에어컨을 스캔합니다.
5. 검색된 기기들의 옵션을 확인하거나, 수동 매핑(Manual Mapping)을 입력하여 설정을 완료합니다.

### ✍️ 수동 매핑 규칙 (Manual Mapping Format)

능동 스캔으로 잡히지 않은 기기를 강제로 등록하거나, 상세 옵션을 일괄 지정할 때 아래 형식을 사용합니다. 여러 대일 경우 쉼표(`,`)로 구분합니다.

> `엔티티번호:통신주소/기기이름/난방유무/음이온유무/타입`

* **엔티티번호:** HA에 등록될 센서 식별 번호 (예: `01`)
* **통신주소:** 에어컨의 실제 하드웨어 주소 HEX값 (예: `01`, `0A`)
* **난방유무:** 난방 지원 시 `1`, 냉방 전용 시 `0`
* **음이온유무:** 플라즈마(음이온) 지원 시 `1`, 미지원 시 `0`
* **타입 (M/S):** 다배관(시스템 에어컨)은 `M`, 단배관(가정용 2in1)은 `S`

**예시:** 
`01:01/거실 에어컨/0/0/M, 02:02/안방 에어컨/0/0/M`

## 📊 제공되는 엔티티 (Entities)

| 플랫폼 | 엔티티 종류 | 설명 |
| :--- | :--- | :--- |
| **Climate** | `climate.lgac_..._cm` | 온도, 모드, 풍량(터보/정음 포함), 상하 회전 및 명시적 켜기/끄기 지원 |
| **Number** | `number.lgac_..._sleep_timer` | 수면 타이머 설정 (0 ~ 420분) |
| **Switch** | `switch.lgac_..._child_lock` | 차일드 락 (리모컨 잠금) |
| **Switch** | `switch.lgac_..._plasma_ion` | 플라즈마(음이온) 제어 |
| **Switch** | `switch.lgac_..._lock_temp` | [소프트웨어] HA/월패드 온도 조절 잠금 |
| **Sensor** | `sensor.lgac_..._zone_active_load` | 실내기 가동 부하율 (냉난방 요구량) |
| **Sensor** | `sensor.lgac_..._odu_total_load` | 실외기 총 열부하 (컴프레서 가동률 파악용) |
| **Sensor** | `sensor.lgac_..._pipe_in` | 실내기 배관 입/출구 온도 |
| **Diagnostic** | `sensor.lgac_..._raw_packet` | (기본 비활성화) 통신 디버깅용 패킷 스트림 |

## 🛠️ 문제 해결 (Troubleshooting)

* **통합구성요소 설치 시 화면이 깨지거나 코드로 나옵니다:**
  HA 프론트엔드 캐시 문제입니다. 브라우저에서 `Ctrl + Shift + R`을 누르거나, 스마트폰 컴패니언 앱 설정에서 '프론트엔드 캐시 지우기'를 실행하세요.
* **기기 상태가 계속 Unavailable(사용 불가)로 나옵니다:**
  입력한 IP와 포트가 맞는지 확인하시고, EW11의 RS485 A/B 선이 뒤바뀌지 않았는지 확인하세요. 60초간 응답 패킷이 없으면 자동으로 오프라인 처리됩니다.
* **목표 온도를 조절했는데 엉뚱한 온도로 튑니다:**
  해당 에어컨이 시스템(다배관)인지 벽걸이(단배관)인지 확인 후, 설정의 매핑 옵션에서 타입을 `M` 또는 `S`로 알맞게 변경하여 재등록해 주세요.
* **풍량을 '정음'이나 '터보'로 바꿨는데 '약풍'이나 '중풍'으로 되돌아옵니다:**
  에어컨 기판이 표준 LGAP 대신 레거시 헤더를 요구할 수 있습니다. 기기를 다시 설정(Configure)하거나 지우고 다시 추가하면서 **'명령어 헤더 방식'을 '레거시 방식'으로 선택**해 보세요.
