# LG AC PI485 (EW11) Integration for Home Assistant

LG 시스템 에어컨 및 가정용 에어컨을 PI485 인터페이스와 RS485 to TCP 게이트웨이(Elfin EW11 등)를 통해 Home Assistant에 연결하고 제어하는 커스텀 통합구성요소(Custom Component)입니다.

이 통합구성요소는 통신 안정성을 극대화하고, LG의 상업용 빌딩 제어망(LonWorks) 표준 센서 데이터를 분석하여 홈어시스턴트에서 에어컨의 실시간 부하 상태를 정밀하게 모니터링할 수 있도록 설계되었습니다.

## ✨ 주요 기능 (Features)

*   **능동형 기기 스캔 (Active Discovery):** 설치 시 RS485 버스를 스캔하여 연결된 에어컨의 실제 하드웨어 통신 주소(Zone Number)를 자동으로 찾아냅니다.
*   **다배관/단배관 맞춤형 온도 제어:** 시스템 에어컨(다배관, M)과 가정용 2in1(단배관, S)의 통신 규격 차이를 반영하여 설정 온도가 튀는 현상을 완벽하게 방지합니다.
*   **낙관적 UI 업데이트 (Optimistic Update):** 명령을 내리는 즉시 UI에 상태를 반영하여 온도 및 풍량 조절 시 화면이 튕기는(Bouncing) 현상을 제거했습니다.
*   **소프트웨어 수면 타이머:** HA 서버 시간을 기준으로 정확하게 카운트다운하며, 시간이 0이 되면 기기의 현재 상태를 보존한 채 안전하게 OFF 명령 패킷을 발송합니다.
*   **LonWorks BMS 고급 센서:** 단순 온도를 넘어 실내기 가동 부하, 실외기 총 열부하 등 인버터 컴프레서의 딥한 상태를 실시간으로 모니터링합니다.
*   **통신 단절 방어 및 자동 복구:** 60초 이상 패킷이 수신되지 않으면 기기를 오프라인(Unavailable) 처리하며, 소켓 누수(Socket Leak)를 방지하는 강력한 재연결 로직이 탑재되어 있습니다.

## 🔌 하드웨어 요구사항 (Hardware Requirements)

1.  **LG PI485 모듈:** 에어컨 실외기 또는 실내기에 연결되어 RS485 통신을 지원하는 모듈 (예: PMNFP14A1 등)
2.  **RS485 to TCP/IP 게이트웨이:** Elfin EW11, USR-TCP232 등 (네트워크를 통해 Serial 데이터를 소켓으로 전송할 수 있는 기기)
3.  **Home Assistant OS / Core**

## 📥 설치 방법 (Installation)

### 수동 설치 (Manual)
1. HA 설정 폴더의 `custom_components` 디렉토리 안에 `lgac_pi485_ew11` 폴더를 생성합니다.
2. 이 저장소의 모든 파일을 해당 폴더로 복사합니다.
3. Home Assistant를 재시작합니다.
4. **[필수]** 브라우저 캐시를 지우기 위해 `Ctrl` + `Shift` + `R` 을 눌러 강력 새로고침을 합니다.

## ⚙️ 설정 방법 (Configuration)

1. Home Assistant의 **설정 > 기기 및 서비스 > 통합구성요소 추가**를 클릭합니다.
2. **"LG 에어컨 (LG AC PI485 EW11)"**을 검색하여 선택합니다.
3. EW11(게이트웨이)의 **IP 주소**와 **포트(Port)**를 입력합니다.
4. 검색 대기 시간을 설정하고 다음으로 넘어가면, 시스템이 자동으로 연결된 에어컨을 스캔합니다.
5. 검색된 기기들의 세부 옵션이나 검색되지 않은 기기의 **수동 매핑(Manual Mapping)**을 입력합니다.

### ✍️ 수동 매핑 규칙 (Manual Mapping Format)

능동 스캔으로 잡히지 않은 기기를 강제로 등록하거나, 옵션을 수정할 때 아래 형식을 사용합니다. 여러 대일 경우 쉼표(`,`)로 구분합니다.

> `엔티티번호:통신주소/기기이름/난방유무/음이온유무/타입`

*   **엔티티번호:** HA에 등록될 센서 번호 (예: `01`)
*   **통신주소:** 에어컨의 실제 하드웨어 주소 (예: `01`, `02`)
*   **난방유무:** 난방 지원 시 `1`, 냉방 전용 시 `0`
*   **음이온유무:** 플라즈마(음이온) 지원 시 `1`, 미지원 시 `0`
*   **타입 (M/S):** 시스템/다배관 에어컨은 `M`, 가정용/단배관은 `S`

**예시:** 
`01:01/거실 에어컨/0/0/M, 02:02/안방 에어컨/0/0/M`
*(해석: 거실 에어컨은 통신주소 01번, 난방 미지원, 음이온 미지원, 다배관 모델)*

## 📊 제공되는 엔티티 (Entities)

통합구성요소가 성공적으로 설정되면 각 에어컨마다 다음과 같은 엔티티들이 생성됩니다.

| 플랫폼 | 엔티티 종류 | 설명 |
| :--- | :--- | :--- |
| **Climate** | `climate.lgac_...` | 온도 조절, 모드(냉방/난방/송풍/제습/자동), 풍량, 회전 제어 |
| **Number** | `number.lgac_..._sleep_timer` | 수면 타이머 설정 (0 ~ 420분) |
| **Switch** | `switch.lgac_..._child_lock` | 차일드 락 (리모컨 잠금) |
| **Switch** | `switch.lgac_..._plasma_ion` | 플라즈마(음이온) 기능 켜기/끄기 |
| **Sensor** | `sensor.lgac_..._pipe_in` | 실내기 배관 입구 온도 |
| **Sensor** | `sensor.lgac_..._pipe_out` | 실내기 배관 출구 온도 |
| **Sensor** | `sensor.lgac_..._zone_active_load` | 실내기 가동 부하율 (냉난방 요구량) |
| **Sensor** | `sensor.lgac_..._odu_total_load` | 실외기 총 열부하 (컴프레서 가동율 파악용) |

## 🛠️ 문제 해결 (Troubleshooting)

*   **통합구성요소 설치 시 화면이 깨지거나 코드로 나옵니다:**
    HA 프론트엔드 캐시 문제입니다. 브라우저에서 `Ctrl + Shift + R`을 누르거나, 스마트폰 컴패니언 앱 설정에서 '프론트엔드 캐시 지우기'를 실행하세요.
*   **기기 상태가 계속 Unavailable(사용 불가)로 나옵니다:**
    입력한 IP와 포트가 맞는지 확인하시고, EW11의 RS485 A/B 선이 뒤바뀌지 않았는지 확인하세요. 60초간 응답 패킷이 없으면 오프라인으로 처리됩니다.
*   **목표 온도를 조절했는데 엉뚱한 온도로 튑니다:**
    해당 에어컨이 시스템(다배관)인지 벽걸이(단배관)인지 확인 후, 설정의 매핑 옵션에서 타입을 `M` 또는 `S`로 알맞게 변경하여 재등록해 주세요.
